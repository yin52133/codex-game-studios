# /art-bible

Guided, section-by-section Art Bible authoring. Creates the visual identity specification that gates all asset production. Run after /brainstorm is approved and before /map-systems or any GDD authoring begins. (source alias: /art-bible).

## Arguments

- `input`: [--review full|lean|solo]

## Workflow

1. Use the `$codex-game-studios:art-bible` skill.
2. Read only the role, template, rule, or engine references that the skill requests.
3. Apply repository `AGENTS.md` instructions before editing files.
4. Report the concrete artifact paths and verification result.

## Examples

```text
/art-bible <task details>
```
