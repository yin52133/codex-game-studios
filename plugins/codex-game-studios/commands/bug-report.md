# /bug-report

Creates a structured bug report from a description, or analyzes code to identify potential bugs. Ensures every bug report has full reproduction steps, severity assessment, and context. (source alias: /bug-report).

## Arguments

- `input`: [description] | analyze [path-to-file]

## Workflow

1. Use the `$codex-game-studios:bug-report` skill.
2. Read only the role, template, rule, or engine references that the skill requests.
3. Apply repository `AGENTS.md` instructions before editing files.
4. Report the concrete artifact paths and verification result.

## Examples

```text
/bug-report <task details>
```
