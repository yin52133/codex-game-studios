# /playtest-report

Generates a structured playtest report template or analyzes existing playtest notes into a structured format. Use this to standardize playtest feedback collection and analysis. (source alias: /playtest-report).

## Arguments

- `input`: [new|analyze path-to-notes] [--review full|lean|solo]

## Workflow

1. Use the `$codex-game-studios:playtest-report` skill.
2. Read only the role, template, rule, or engine references that the skill requests.
3. Apply repository `AGENTS.md` instructions before editing files.
4. Report the concrete artifact paths and verification result.

## Examples

```text
/playtest-report <task details>
```
