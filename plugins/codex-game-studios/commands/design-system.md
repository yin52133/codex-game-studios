# /design-system

Guided, section-by-section GDD authoring for a single game system. Gathers context from existing docs, walks through each required section collaboratively, cross-references dependencies, and writes incrementally to file. (source alias: /design-system).

## Arguments

- `input`: <system-name> [--review full|lean|solo]

## Workflow

1. Use the `$codex-game-studios:design-system` skill.
2. Read only the role, template, rule, or engine references that the skill requests.
3. Apply repository `AGENTS.md` instructions before editing files.
4. Report the concrete artifact paths and verification result.

## Examples

```text
/design-system <task details>
```
