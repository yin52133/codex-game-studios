# /prototype

Concept prototype — validate the core idea is worth designing before writing GDDs. Run right after /brainstorm and /setup-engine. Routes to HTML, Engine, or Paper path based on game type. Produces a throwaway build and a PROCEED/PIVOT/KILL verdict. (source alias: /prototype).

## Arguments

- `input`: [concept-description] [--path html|engine|paper] [--review full|lean|solo] [--spike]

## Workflow

1. Use the `$codex-game-studios:prototype` skill.
2. Read only the role, template, rule, or engine references that the skill requests.
3. Apply repository `AGENTS.md` instructions before editing files.
4. Report the concrete artifact paths and verification result.

## Examples

```text
/prototype <task details>
```
