# /retrospective

Generates a sprint or milestone retrospective by analyzing completed work, velocity, blockers, and patterns. Produces actionable insights for the next iteration. (source alias: /retrospective).

## Arguments

- `input`: [sprint-N|milestone-name]

## Workflow

1. Use the `$codex-game-studios:retrospective` skill.
2. Read only the role, template, rule, or engine references that the skill requests.
3. Apply repository `AGENTS.md` instructions before editing files.
4. Report the concrete artifact paths and verification result.

## Examples

```text
/retrospective <task details>
```
