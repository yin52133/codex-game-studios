# /patch-notes

Generate player-facing patch notes from git history, sprint data, and internal changelogs. Translates developer language into clear, engaging player communication. (source alias: /patch-notes).

## Arguments

- `input`: [version] [--style brief|detailed|full]

## Workflow

1. Use the `$codex-game-studios:patch-notes` skill.
2. Read only the role, template, rule, or engine references that the skill requests.
3. Apply repository `AGENTS.md` instructions before editing files.
4. Report the concrete artifact paths and verification result.

## Examples

```text
/patch-notes <task details>
```
