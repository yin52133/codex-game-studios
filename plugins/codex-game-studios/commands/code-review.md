# /code-review

Performs an architectural and quality code review on a specified file or set of files. Checks for coding standard compliance, architectural pattern adherence, SOLID principles, testability, and performance concerns. (source alias: /code-review).

## Arguments

- `input`: [path-to-file-or-directory]

## Workflow

1. Use the `$codex-game-studios:code-review` skill.
2. Read only the role, template, rule, or engine references that the skill requests.
3. Apply repository `AGENTS.md` instructions before editing files.
4. Report the concrete artifact paths and verification result.

## Examples

```text
/code-review <task details>
```
