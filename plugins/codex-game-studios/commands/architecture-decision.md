# /architecture-decision

Creates an Architecture Decision Record (ADR) documenting a significant technical decision, its context, alternatives considered, and consequences. Every major technical choice should have an ADR. (source alias: /architecture-decision).

## Arguments

- `input`: [title] [--review full|lean|solo]

## Workflow

1. Use the `$codex-game-studios:architecture-decision` skill.
2. Read only the role, template, rule, or engine references that the skill requests.
3. Apply repository `AGENTS.md` instructions before editing files.
4. Report the concrete artifact paths and verification result.

## Examples

```text
/architecture-decision <task details>
```
