Manual Review Gates

  1. Role authority review: confirm role references do not overclaim autonomous authority and still preserve escalation paths.
  2. Skill behavior review: confirm each high-impact workflow skill uses Codex collaboration rules, especially before file writes and multi-file changes.
  3. License and attribution review: confirm upstream license and source attribution are included in the plugin package.
  4. Hook schema review: confirm Codex hook registration before enabling any automatic hook behavior.

Rollout Steps

  1. Local review package: generate the plugin under plugins/codex-game-studios and keep marketplace registration disabled. Verify file counts and JSON validity.
  2. Reviewer trial: enable the repo-local marketplace entry and run one concept workflow plus one review workflow in a disposable game project.
  3. Compatibility pass: capture every manual workaround needed during the trial and update the relevant skill or reference.
  4. Release candidate: mark checklist items complete, keep unsupported hook registration documented, and tag the plugin version as 0.1.0.

Open Risks

Risk Impact Mitigation
Codex custom-agent schema is unavailable or different from Claude's agent schema. Role prompts cannot be installed as executable custom agents. Preserve roles as references and route them from skills. Add generated agent files only after schema confirmation.
Hook event schema differs from Claude events. Automatic validation hooks may fire at wrong times or receive incompatible input. Keep hooks as manual scripts until schema validation passes.
Large converted skills overload Codex context. Skill use becomes noisy and less reliable. Move examples, templates, and long catalogs into references; keep SKILL.md procedural.
Claude include syntax is copied into Codex instructions. Important rules may silently fail to load. Resolve includes during generation and validate that no unresolved @path remains in runtime instructions.
